# FK Financial Kinetics — public preview package

Static HTML/CSS/JavaScript. Open `index.html` locally or deploy the folder contents to a static host. No build tools required.

## GitHub Pages (free static preview)
1. Create a GitHub repository and upload **the contents of this folder** to its root.
2. Repository → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
3. Wait for the published address shown in Pages. Test all modules at that actual URL.
4. Before public promotion, complete `LAUNCH-CHECKLIST.md`, replace TODO(OWNER) items in the legal/information pages, and check the real hosting-provider privacy/security configuration.

## Limitations
- Virtual chips only; no real money.
- Local save key `fk-casino-v1` intentionally preserved for backwards compatibility.
- No verified identities, cloud saving, shared accounts or global leaderboards.
- Browser storage can be edited, lost or cleared; not a secure source of truth.
- Do not claim legal compliance or production security review from this package.
